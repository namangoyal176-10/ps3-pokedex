
# PS3 - Pokédex

A Pokémon explorer built with React, React Router, and PokeAPI.

## Assignment Details
- **PS Number:** PS3
- **Project Name:** Pokédex
- **Frontend:** React + Vite
- **Routing:** React Router DOM
- **API:** [PokeAPI](https://pokeapi.co/)

## Features
- Browse 50 Pokémon
- Search Pokémon by name
- View Pokémon artwork and details
- Display types, height, weight, and base stats
- Responsive Pokémon card grid
- Loading and error messages
- 404 Not Found page

## Routes

| Route | Description |
|---|---|
| `/` | Home page |
| `/pokemon` | Pokémon list and search |
| `/pokemon/:name` | Pokémon details |
| `*` | Not Found page |

## API Endpoints
- `https://pokeapi.co/api/v2/pokemon?limit=50`
- `https://pokeapi.co/api/v2/pokemon/pikachu`
